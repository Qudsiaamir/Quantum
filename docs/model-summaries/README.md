# Model Summaries

This directory contains captured model architecture summaries from earlier experiments.

- `pennylane_classical_resnet.txt`: ResNet summary with a classical linear head.
- `pennylane_quantum_resnet.txt`: ResNet summary with a PennyLane-style quantum head.
- `pspnet_model.txt`: PSPNet architecture summary.

These files are documentation artifacts, not runnable source modules.
