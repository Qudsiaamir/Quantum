# Data

Place raw Kaggle data files in `data/raw/`.

The notebook expects the Home Credit Default Risk CSV files from:

https://www.kaggle.com/competitions/home-credit-default-risk/data

The required files for the main notebook workflow are:

- `application_train.csv`
- `application_test.csv`

The other competition files are useful for future feature engineering work but are not required by the current baseline notebook.
